# Reports

Este directorio contiene los entregables y productos analíticos del estudio:

- `Estudio de Mercado y Analisis Competitivo para Proyectos Inmobiliarios en La Victoria.pdf`: Informe ejecutivo final del estudio de mercado.
- `figures/estudio_lar/`: Mapas cartográficos finales (`Layout 1.png` a `Layout 5.png`) correspondientes a las composiciones de impresión del estudio.
- `tables/`: Tablas de resultados analíticos.
- `exports/`: Entregables y exportaciones derivados.

Notas de gobernanza:
1. Los archivos presentes representan entregables históricos. Su presencia no certifica que puedan regenerarse automáticamente mediante scripts en el estado actual (ver [`docs/LINEAGE.md`](../docs/LINEAGE.md)).
2. La documentación sobre procesos de validación y evidencia de ejecuciones no se almacena aquí, sino en `docs/reports/`.
3. No utilizar este directorio como almacenamiento de datos raw ni como fuente de verdad de contracts.
