# Notebooks

Este directorio está intencionalmente vacío de análisis.

Cuando llegue la data raw, usar notebooks para inventario, perfilado y exploración. Las transformaciones necesarias para reproducir resultados deben trasladarse a `src/`.

Convención sugerida cuando empiece el trabajo:

```text
00_... inventario/perfilado
01_... preparación
02_... exploración
03_... análisis
```

La numeración es organizativa y no implica una metodología predeterminada.
