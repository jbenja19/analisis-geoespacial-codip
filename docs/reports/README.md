# Evidencia de proceso

Este directorio está reservado para evidencia histórica de ejecuciones, validaciones o cierres metodológicos que merezcan conservarse independientemente de los outputs analíticos.

No duplicar aquí:

- el estado vigente (`docs/CURRENT_STATE.md`);
- decisiones (`docs/decisions/`);
- figuras, tablas, exports o el informe analítico (`reports/`).

Un reporte de proceso debe indicar qué se ejecutó, sobre qué fuente/commit, qué validación se realizó y qué limitaciones permanecieron.
